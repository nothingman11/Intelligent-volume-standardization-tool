# Intelligent-volume-standardization-tool
这是一个专为处理大批量录音所设计的批量音频处理脚本。它基于 Python 和 pydub，能够自动扫描文件夹，将音量过小的音频标准化到目标响度，同时严格防止削波失真（破音）。

✨ 核心功能
🎯 智能标准化：自动计算增益，将音频平均响度（dBFS）提升至预设的目标值（默认 -15 dBFS）。
🛡️ 防破音保护 (Anti-Clipping)：内置安全峰值限制逻辑。如果提升音量会导致峰值超过阈值（如 -1.0 dBFS），脚本会自动减少增益，确保输出文件绝对不破音。


⏭️ 高效跳过机制：
若文件音量已达标（高于跳过阈值），直接复制，不进行重编码，保留原始音质。
支持断点续传：若目标文件已存在且完整，自动跳过，方便处理中途意外中断的情况。

📂 目录结构保持：递归处理子文件夹，并在目标目录中完美还原相同的文件夹结构。

🔒 本地 FFmpeg 锁定：优先使用脚本同目录下的 ffmpeg.exe，避免系统环境变量冲突，确保处理速度稳定。

⚙️ 关键参数配置 (使用前必读)
在使用脚本前，请务必打开 fix_xiao_volume.py，修改顶部的 配置区域。以下是需要重点调整的参数：

处理后文件的保存位置。	必须修改
