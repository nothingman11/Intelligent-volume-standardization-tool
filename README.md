# 🎚️ Intelligent Volume Standardization Tool

> 一个专为处理大批量录音设计的智能音频批量处理脚本。基于 Python 和 `pydub`，自动扫描文件夹，将音量标准化至目标响度，并严格防止削波失真（破音）。

## ✨ 核心功能

- 🎯 **智能标准化**  
  自动计算增益，将音频平均响度（dBFS）提升至预设目标值（默认 `-15 dBFS`）。
  
- 🛡️ **防破音保护 (Anti-Clipping)**  
  内置安全峰值限制逻辑。若提升音量会导致峰值超过阈值（如 `-1.0 dBFS`），脚本会自动降低增益，确保输出文件绝对不破音。

- ⏭️ **高效跳过机制**  
  - **智能检测**：若文件音量已达标（高于跳过阈值），直接复制原文件，不进行重编码，保留原始音质。
  - **断点续传**：若目标文件已存在且完整，自动跳过，方便处理中途意外中断的情况。

- 📂 **目录结构保持**  
  递归处理子文件夹，并在目标目录中完美还原相同的文件夹结构。

- 🔒 **本地 FFmpeg 锁定**  
  优先使用脚本同目录下的 `ffmpeg.exe`，避免系统环境变量冲突，确保处理速度稳定。

## ⚙️ 关键参数配置 (使用前必读)

在使用脚本前，请务必打开 `fix_xiao_volume.py`，修改顶部的 **配置区域**。

### 📋 参数说明表

| 参数名 | 默认值 | 说明 | 建议操作 |
| :--- | :--- | :--- | :--- |
| `SOURCE_DIR` | `r"G:\...\Xiao C"` | **源文件夹路径**<br>存放原始录音的目录。 | **必须修改**<br>改为需增益音频的实际路径 |
| `TARGET_DIR` | `r"D:\...\Xiao C"` | **目标文件夹路径**<br>处理后文件的保存位置。 | **必须修改**<br>建议设为空文件夹 |
| `TARGET_DBFS` | `-15.0` | **目标平均音量**<br>希望达到的响度水平。 | 按需微调<br>`-12`(更响) ~ `-18`(保守) |
| `MAX_PEAK_LIMIT` | `-1.0` | **绝对峰值上限**<br>防止数字削波的“硬天花板”。 | 通常无需修改<br>保持 `-1.0` 或 `-0.5` |
| `SKIP_THRESHOLD` | `-25.0` | **跳过阈值**<br>高于此音量的文件将被直接复制。 | 按需微调<br>若录音普遍很轻，可调低至 `-30` |

### 💻 配置示例代码

请在脚本顶部找到并修改以下部分（注意 Windows 路径前加 `r`）：

```python
# 1. 修改为你的实际路径
SOURCE_DIR = r"C:\Users\YourName\Music\Raw_Xiao_Recordings"
TARGET_DIR = r"C:\Users\YourName\Music\Normalized_Xiao"

# 2. 根据听感调整目标音量
TARGET_DBFS = -15.0   # 推荐范围: -18.0 (保守) 到 -12.0 (激进)

# 3. 安全限制 (通常保持不变)
MAX_PEAK_LIMIT = -1.0 
SKIP_THRESHOLD = -25.0
```
